# 생태계에서 온 엽서 — GitHub / Vercel 배포용

4학년 과학 2단원 2차시용입니다. 숲·바다·강·어항·화단·연못의 실감 나는 AI 교육용 이미지 6종을 포함합니다. 개인 관찰 카드를 수집하지 않으며, 다음 차시의 생물/비생물 분류나 먹이 관계는 요구하지 않습니다.

## 배포
1. 이 폴더 안의 파일과 app, public 폴더를 GitHub 저장소에 올립니다. 압축 파일 자체를 올리지 마세요.
2. Firebase 프로젝트에서 Cloud Firestore 데이터베이스를 생성합니다. 브라우저 직접 접근은 필요 없으므로 첨부 firestore.rules처럼 읽기·쓰기를 모두 차단합니다. 서버의 Admin SDK만 접근합니다.
3. Firebase 프로젝트 설정 → 서비스 계정에서 새 비공개 키(JSON)를 생성합니다. 키 파일은 GitHub에 올리지 마세요.
4. Vercel에서 GitHub 저장소를 가져옵니다. Framework Preset은 Next.js, Root Directory는 기본값입니다.
5. Vercel 환경 변수에 FIREBASE_SERVICE_ACCOUNT를 추가합니다. 값은 서비스 계정 JSON 파일의 전체 내용입니다. 이 변수에 NEXT_PUBLIC_ 접두사를 붙이지 않습니다.
6. Deploy를 누릅니다. 환경 변수를 나중에 추가했다면 Redeploy합니다.

## 수업 운영
1. 교사가 첫 화면의 ‘교사용 · 새 수업 만들기’를 누릅니다.
2. 학생 공통 링크를 공유합니다. 학생은 1~6모둠 버튼 중 자기 모둠을 선택하면 현재 수업에 자동 연결됩니다. 수업 코드 입력은 없습니다. 학생 로그인은 필요하지 않습니다.
3. 모둠이 원하는 생태계를 이야기하면 교사가 각 모둠 카드에서 지정합니다. 같은 생태계 중복 지정도 가능합니다. 이미 지정한 장소를 바꾸려면 새 수업을 만듭니다.
4. 학생은 사진을 확대하며 한 사람씩 발견한 것을 말합니다. 토의 질문은 ‘무엇이 보이나요? / 어디에서 찾았나요? / 엽서에 무엇을 소개할까요?’입니다.
5. 모둠당 한 명이 글을 입력하고 ‘글 저장’을 누릅니다. 다른 기기에서 약 2초마다 최신 내용을 확인합니다. 모둠원도 수정할 수 있지만 같은 항목을 동시에 저장하면 충돌 안내가 나옵니다.
6. 동물의 입장에서 사는 곳을 소개하고 테두리·스티커를 꾸민 뒤 제출합니다. 제출 후에는 교사가 ‘수정 허용’을 눌러야 다시 고칠 수 있습니다.
7. 교사는 발표 화면에서 모둠 엽서를 확대하고 관찰 사진을 함께 보여 줍니다. 발표 단계에서는 학생 수정이 잠깁니다.
8. 학생은 저장된 엽서를 PNG로 내려받을 수 있습니다. 다운로드 전에 글 저장을 완료합니다.

교사 권한은 수업 생성에 사용한 브라우저에 보관합니다. 다른 기기로 옮기려면 기존 브라우저를 유지하세요. 마지막으로 만든 수업만 ‘이전 수업 관리’로 복구됩니다. 발표 화면 링크는 ?mode=board&room=수업코드 형식입니다.

## 확인 범위
동일 화면의 Sites 버전은 TypeScript 검사와 배포 빌드, 서버 저장·권한·충돌 처리를 검증했습니다. 이 Vercel 패키지는 동일 UI와 Firebase 서버 어댑터를 포함하지만 사용자 Firebase 프로젝트 연결과 실제 Vercel 배포는 완료하지 않았습니다. 배포 후 교사와 학생 기기를 이용해 지정→저장→제출→발표를 한 번 확인하세요.

수업 코드를 아는 사람은 해당 수업의 학생 활동에 참여할 수 있으므로 수업 내부에서 공유합니다. 학생 이름·개인정보 입력은 필요 없습니다.

## 코드 없는 입장 업데이트
app/page.tsx, app/globals.css, app/api/classroom/route.ts를 모두 교체하고 Vercel에 재배포합니다. Firebase 환경 변수는 그대로 유지합니다. 새 수업을 한 번 만들면 현재 수업이 자동 지정됩니다. 기존 데이터에 수업이 하나뿐이면 그 수업도 자동 연결됩니다. 이미 입장한 학생은 새 수업 생성 시 기존 수업에 남으며, 처음 화면으로 돌아와 모둠을 선택하면 새 수업에 입장합니다.
